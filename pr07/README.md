# Практическая работа №7. Случайный лес

**Вариант:** C

## Цель работы
Обучить Random Forest, сравнить его с Decision Tree и исследовать важность признаков с помощью встроенной важности, Permutation Importance и SHAP.

## Используемые методы
- Decision Tree — одиночное дерево решений.
- Random Forest — ансамбль из 100 деревьев.
- Built-in Feature Importance — встроенная оценка важности признаков.
- Permutation Importance — оценка влияния признаков на качество модели.
- SHAP — объяснение предсказаний модели.

## Сравнение моделей
Результаты Accuracy, Precision, Recall, F1-score и ROC-AUC представлены в ноутбуке `random_forest.ipynb`.

## Анализ важности признаков
Встроенная важность показывает вклад признаков в разделения деревьев. Permutation Importance оценивает изменение качества при перемешивании признака. SHAP объясняет вклад признаков в предсказания отдельных объектов.

Результаты методов могут различаться из-за корреляции признаков и особенностей расчёта важности. Важность признака не означает, что он является причиной ухода абонента.

## Вывод
В работе обучены и сравнены Decision Tree и Random Forest. Исследованы три подхода к объяснению моделей. Окончательные выводы о качестве моделей и наиболее важных признаках необходимо делать по фактическим результатам эксперимента.
