# Практическая работа № 4. Регрессионная модель

## Цель работы
Реализовать градиентный спуск для линейной регрессии на NumPy и сравнить его со Scikit-learn.

## Выполненные задачи
1. Создан учебный датасет для предсказания стоимости жилья.
2. Данные разделены на обучающую и тестовую выборки.
3. Реализованы функция потерь MSE и её градиент.
4. Реализован алгоритм градиентного спуска.
5. Обучена модель LinearRegression из Scikit-learn.
6. Рассчитаны метрики MAE, RMSE и R².
7. Исследовано влияние скорости обучения.
8. Построены графики сходимости и предсказаний.

## Используемые библиотеки
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Результат
Реализована собственная модель линейной регрессии. Её результаты сравниваются с моделью Scikit-learn на тестовой выборке.
