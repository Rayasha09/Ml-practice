# Практическая работа № 1. Настройка окружения и первый Notebook

**ФИО:** Ибрагимова Райена

## Цель работы
Выполнить первичный анализ датасета `tips` с использованием Python, Pandas, NumPy, Matplotlib и Seaborn.

## Структура проекта
- `notebook.ipynb` — ноутбук с анализом данных.
- `data/tips.csv` — датасет с данными о счетах и чаевых в ресторане.

## Выполненные задачи
1. Загрузка и изучение датасета.
2. Проверка размера таблицы и типов данных.
3. Анализ пропущенных значений.
4. Получение описательной статистики.
5. Построение графиков распределения счетов и количества заказов по дням недели.

## Результат
Проведён первичный анализ данных и построены графики для изучения основных характеристик датасета.
