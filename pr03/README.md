# Практическая работа № 3

## Сборка пайплайна предобработки данных

### Цель работы
Создать пайплайн предобработки данных с использованием библиотеки Scikit-learn и научиться правильно обрабатывать обучающую и тестовую выборки.

### Выполненные задачи
1. Создан учебный датасет с числовыми и категориальными признаками.
2. Данные разделены на обучающую и тестовую выборки.
3. Создан собственный трансформер для обработки выбросов.
4. Пропуски обработаны с помощью `SimpleImputer`.
5. Категориальные признаки преобразованы с помощью `OneHotEncoder`.
6. Числовые признаки масштабированы с помощью `StandardScaler`.
7. Обработка объединена с помощью `Pipeline` и `ColumnTransformer`.
8. Проверена работа предобработки на обучающих и тестовых данных.

### Результат
Создан пайплайн предобработки данных. Для предотвращения утечки данных метод `fit_transform()` используется на обучающей выборке, а `transform()` — на тестовой.

### Используемые библиотеки
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
